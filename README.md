# Manifesto for a Self-Organizing System Built to Last Millennia

Humanity's move into space will take thousands of years. No state, company or person lasts that long; only self-governing systems that reproduce without a center can. This repository holds the founding text of one such system. Its first crews are the living prototype.

**Status:** working draft 0.4, open for discussion. The project does not have a name yet.

## Read

- [MANIFESTO.md](MANIFESTO.md) — the full text.
- [CORE.md](CORE.md) — the five principles that no decision can change.

## Take part

- **Discuss.** Open an issue to question, challenge or suggest anything. Disagreement is welcome: the right to disagree is part of the core.
- **Propose a change.** Send a pull request against MANIFESTO.md. For CORE.md, only fixes to spelling and wording are accepted, never changes to its meaning.
- **Found a crew.** Any group of 10–30 people who accept the text can found a crew without anyone's permission. Open an issue so others can find you.

Working languages: English and Georgian.

## Where this repository lives

For now the repository is held on a personal account. Once the project has a name, it will move to a GitHub organization with several owners, because the system has no center and neither should its founding text. Existing links will keep working after the move.
